# Star Plus Travel & Tourism LLC - Official Web Application

Modern, high-performance web platform for **Star Plus Travel & Tourism LLC** (operating in Deira, Dubai, UAE and Colombo, Sri Lanka).

## 🚀 Key Features
- **Hero Background Video Engine**: Silent ambient looping video with smooth dark/light gradient overlay.
- **Dynamic Tour Packages & Interactive Filtering**: Multi-currency converter (AED, USD, EUR, GBP, LKR), itinerary timeline modal, and category filtering.
- **Express Visa Processing Portal**: Real-time requirements calculator and document checklist modal.
- **Our Corporate Clients Marquee**: 60fps continuous infinite right-to-left marquee with hover pause and edge fade masks.
- **Light & Dark Theme Engine**: System OS sync, manual navbar toggles, zero-flicker loader, and dynamic logo switching.
- **Dedicated Careers Portal (`/careers`)**: 6 live job listings with regional email routing (`info@starplustraveluae.com` & `info@starplustravelsl.com`) and interactive resume submission modal.
- **5-Holiday Automatic Theme Manager**: Dynamic Islamic calendar calculation for Ramadan & Eid, plus New Year, Valentine's Day, and Christmas.
- **Continuous Deployment Ready**: Pre-configured for Vercel, Netlify, Cloudflare Pages, and GitHub Actions.
